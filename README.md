## 🚀 Features
- RESTful APIs using Gin
- PostgreSQL with GORM
- JWT Authentication & Middleware
- Environment-based configuration (.env)
- Clean architecture (handlers, services, repository)

## 🛠 Tech Stack
- Go (Golang)
- Gin Framework
- GORM ORM
- PostgreSQL

## ▶️ Run Locally
1. Clone repo
2. Create `.env` file
3. Run:
   go run main.go
